# 📖 텍스트힙 학교 (해커톤 초안)

제1회 교사연구회 연합 AI 해커톤 · 주제 **TEXT HIP** · 대상 초3~4학년

아이소메트릭 학교 마을을 돌아다니며 고전·인문학 책을 체험하고, 내 이야기로 만든 작품을 친구들과 나누는 웹앱입니다.

| 텍스트힙 관점 | 앱에서 구현한 곳 |
|---|---|
| 취향·정체성 | 사서 추천(내 기분·관심사), 나의 사물함(뱃지·스티커), 리그 |
| 지금 | 15소년 표류기 "내가 주인공" 선택 체험, 라임오렌지나무 비밀 나무 편지 |
| 함께 | 학급 문고 속 친구 생각, 우리 반 선택 비율, 학급 문집, 미술실 갤러리, 다른 반 탐방 |

## 실행 방법

```bash
npm install
npm run dev
```

브라우저에서 `http://localhost:5173` 을 엽니다.

- **AI 키 없이도 동작**합니다. 키가 없으면 미리 준비한 예시 답변으로 돌아가요.
- 실제 AI를 쓰려면 `.env.example`을 복사해 `.env`를 만들고 `ANTHROPIC_API_KEY`를 넣으세요. (`.env`는 git에 올라가지 않습니다)
- **GitHub Pages 배포:** 저장소 Settings → Pages → Source를 **GitHub Actions**로 바꾸면 푸시할 때마다 자동으로 빌드·배포됩니다. Pages에는 서버가 없어서 AI는 예시 답변으로 동작합니다.
- 실제 AI까지 쓰려면: `api/ai.js`를 Vercel에 따로 올리고, 빌드 환경변수 `VITE_AI_URL`에 그 주소를 넣으세요.
- 배포(Vercel): Vercel에 올리면 `api/ai.js`가 서버 함수로 자동 동작합니다. 환경변수에 `ANTHROPIC_API_KEY`를 등록하세요.
- 저장: 학생 데이터는 브라우저(localStorage)에 저장됩니다. 상단 ↺ 버튼으로 초기화.

## 게임 방식

- 타이틀 → 캐릭터 고르기 → 시작 스토리(비주얼노벨식 대화) → 걸어 다니는 학교
- **이동:** 방향키·WASD, 또는 땅이나 건물을 눌러서 이동 (태블릿·크롬북)
- **입장:** 건물 문 앞에서 Space/Enter 또는 "들어가기" 버튼
- **그림 넣기:** `public/art/`에 그림을 넣고 `src/data.js`의 `ART`에 경로를 적으면 이모지 대신 그림이 나옵니다 (타이틀 배경, 사서·안내 캐릭터 초상화)

## 시연 흐름 (2분)

1. 닉네임·캐릭터 고르기 → 학교 지도
2. 📚 도서관 → 헤세를 닮은 AI 사서가 책 추천 → 학급 문고에 꽂기 (도토리 +10, 📗 뱃지)
3. 🏫 3학년 2반 → 책 열기 → 친구들 생각 보기 → 체험하러 가기
4. 🏝️ 15소년 표류기 갈림길 3번 (우리 반 선택 비율 표시) → AI 결말 + 표지 → 한 줄 서평 → 문집 저장 (뱃지 + 도토리)
5. 🗄️ 사물함에 뱃지 붙이기 → 🏪 매점에서 스티커 구매
6. 📕 학급 문집 넘겨보기 (해시태그로 모아보기) → 🎨 미술실 → 🏆 리그 → 🚪 3학년 1반 탐방

## 폴더 구조와 4인 분담

```
api/ai.js                 ③ AI 담당: 프롬프트·말투·안전 지시문, 예시 답변(mock)
src/data.js               ② 데이터 담당: 책, 갈림길 대본, 뱃지, 상점, 리그 기준, 시연용 친구 데이터
src/store.js              ② 학생 상태 저장 (나중에 서버 DB로 교체)
src/screens/SchoolMap.jsx ① 학교 화면 담당: 아이소메트릭 지도, 건물 배치(ROOMS)
src/screens/Library.jsx   ③④ 사서 추천
src/screens/Castaway.jsx  ④ 체험 담당: 15소년 표류기
src/screens/Orange.jsx    ④ 라임오렌지나무 (임시 활동: 비밀 나무에게 편지)
src/screens/Finish.jsx    ④ 활동 마무리 공통(표지·서평·뱃지 지급)
src/screens/Classroom.jsx ① 교실·학급 문고·다른 반 탐방
src/screens/Locker.jsx, Shop.jsx, Munjip.jsx, Art.jsx, Board.jsx  ①④ 나머지 공간
src/styles.css            공통 디자인
```

## 새 책 추가하는 법

1. `src/data.js`의 `BOOKS`에 책을 추가하고 `activity`에 화면 이름을 적기
2. `src/screens/`에 체험 화면을 만들고 마지막에 `<Finish …/>`를 넣기
3. `src/App.jsx`의 `SCREENS`에 등록

## 참고 사항

- AI 사서는 "작가를 닮은 AI"로 표기합니다. 실제 작가 본인처럼 말하지 않도록 프롬프트에 넣었습니다.
- 『나의 라임오렌지나무』는 저작권이 남아 있어 원작 문장을 쓰지 않고 활동 중심으로 구성했습니다.
- 표지는 그림 생성 AI 대신 AI가 고른 제목·색·이모지로 SVG를 그려서 빠르고 안정적입니다.
